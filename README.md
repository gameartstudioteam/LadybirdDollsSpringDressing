# Ladybird Dolls Spring Dressing

Public privacy policy for the Android game by GameArtForKids.

- Android package: `com.GameArtForKids.LadybirdDollsSpringDressing`
- Privacy and support contact: [gameartstudioteam@gmail.com](mailto:gameartstudioteam@gmail.com)
- Published policy: [GitHub Pages](https://gameartstudioteam.github.io/LadybirdDollsSpringDressing/)
- Privacy request instructions: [Support and deletion requests](https://gameartstudioteam.github.io/LadybirdDollsSpringDressing/#support)
- Policy source: [index.html](index.html)

The policy describes local game saves, child-directed Google AdMob advertising, technical SDK data, and Google Analytics for Firebase. Update 1.9 is being prepared: gameplay analytics is disabled by default and has a separate parent enable/disable choice. Advertising availability does not enable analytics. A parent can prepare an email request using the analytics app-instance ID when available; the parent sends the email. Local analytics reset does not delete Google's existing records or game progress.

On October 4, 2026, the app's Analytics property was configured for two-month user and event retention, with reset on new activity disabled. These settings do not impose a universal expiry on aggregated reports or advertising data. The public policy explains these limits and the privacy request procedure.

Publishing this policy does not publish the game or confirm Google Play approval. Last updated: October 4, 2026.
